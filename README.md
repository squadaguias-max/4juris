# 4Juris — Catálogo de Templates

Projeto React + Vite + Tailwind CSS para apresentação dos templates de landing pages da 4Juris.

## Comandos

- `npm install` — instala as dependências
- `npm run dev` — inicia o ambiente de desenvolvimento
- `npm run build` — gera a versão de produção em `dist`
- `npm run preview` — visualiza o build de produção

As versões compiladas dos modelos estão em `public/templates`.
